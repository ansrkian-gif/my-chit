# Daybook

Personal daily expense tracker with a once-a-day budget check-in popup.

## Features

- Add expenses with amount, category, note, and date
- Set a monthly budget and currency (defaults to KWD)
- Daily popup showing spent today and remaining budget
- Progress ring for the month, today’s list, and recent days
- Works offline as a lightweight PWA (data stored in your browser)

## Run locally

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open `http://127.0.0.1:4173`.
